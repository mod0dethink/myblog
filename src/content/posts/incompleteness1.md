ゲーデルの第一不完全性定理の証明を、何回かに分けて追っていくシリーズです。

第一不完全性定理は、おおまかに言うと次のような定理です。

> 自然数の基本的な計算を扱える程度に強く、公理を機械的に列挙できる理論が無矛盾ならば、その理論では証明も反証もできない文が存在する。

きちんと証明を追おうとすると、準備することが意外と多くあります。このシリーズでは、次の順番で進めていく予定です。

1. ペアノ算術（今回）
2. ゲーデル数
3. 表現可能性
4. 対角化補題
5. 第一不完全性定理

命題論理と述語論理については、ひととおり知っているものとして進めます。具体的には、論理式、自由変数と束縛変数、形式的な証明、モデルといった用語を、説明なしで使います。

## 記法

記号の使い方は本によって少しずつ違うので、最初にこのシリーズでの書き方をまとめておきます。

- 論理記号は $\lnot$（否定）、$\land$（かつ）、$\lor$（または）、$\to$（ならば）、$\leftrightarrow$（同値）、$\forall$、$\exists$ を使います。等号 $=$ も論理記号として扱います。
- 自由変数を持たない論理式を「文」と呼びます。
- 文の集合を「理論」と呼びます。理論に属する文が、その理論の公理です。
- 理論 $T$ から文 $\varphi$ が証明できることを $T \vdash \varphi$ と書きます。証明体系は、一階述語論理の標準的なもの（ヒルベルト流や自然演繹など）であれば、どれを使っても構いません。
- $T \vdash \varphi$ かつ $T \vdash \lnot\varphi$ となる文 $\varphi$ が存在しないとき、$T$ は「無矛盾」であるといいます。
- どんな文 $\varphi$ についても $T \vdash \varphi$ か $T \vdash \lnot\varphi$ のどちらかが成り立つとき、$T$ は「完全」であるといいます。

最後の「完全」は、完全性定理の「完全」とは別の意味です。不完全性定理が述べているのは、ある条件を満たす理論は、ここでいう意味で完全にはなれない、ということです。

## 算術の言語

ペアノ算術（Peano Arithmetic、以下 $\mathsf{PA}$）は、自然数についての理論です。まず、$\mathsf{PA}$ で使う記号を決めます。

- 定数記号 $0$
- 1変数の関数記号 $S$
- 2変数の関数記号 $+$ と $\times$

$S$ は「次の数」を表す記号で、後者関数と呼ばれます。$S(0)$ が 1、$S(S(0))$ が 2 を表します。

この言語には $1$ や $2$ といった記号はありません。自然数 $n$ を表したいときは、$0$ に $S$ を $n$ 回適用した項を使います。これを $n$ の「数項」と呼び、$\overline{n}$ と書くことにします。

$$
\overline{0} = 0, \qquad \overline{1} = S(0), \qquad \overline{2} = S(S(0)), \qquad \ldots
$$

大小関係の記号 $<$ も、言語には入っていません。必要なときは、$x < y$ を次の論理式の省略として使います。

$$
\exists z \, (x + S(z) = y)
$$

## 公理

$\mathsf{PA}$ の公理は次のとおりです。

1. $\forall x \, \lnot (S(x) = 0)$
2. $\forall x \, \forall y \, (S(x) = S(y) \to x = y)$
3. $\forall x \, (x + 0 = x)$
4. $\forall x \, \forall y \, (x + S(y) = S(x + y))$
5. $\forall x \, (x \times 0 = 0)$
6. $\forall x \, \forall y \, (x \times S(y) = (x \times y) + x)$
7. 論理式 $\varphi(x)$ ごとに、次の文（数学的帰納法）

$$
\bigl( \varphi(0) \land \forall x \, (\varphi(x) \to \varphi(S(x))) \bigr) \to \forall x \, \varphi(x)
$$

1 と 2 は後者関数についての公理です。1 は「0 はどの数の次の数でもない」、2 は「次の数が等しければ、もとの数も等しい」と言っています。

3 と 4 は足し算、5 と 6 は掛け算の定義にあたります。どちらも「0 のとき」と「次の数のとき」を決める、再帰的な定義の形になっています。

7 は数学的帰納法です。7 はひとつの公理ではなく、論理式 $\varphi(x)$ をひとつ決めるごとに公理がひとつ得られます。つまり、無限個の公理をまとめて書いたものです。このような書き方を公理図式といいます。なお、$\varphi(x)$ は $x$ 以外の自由変数を含んでいても構いません。その場合は、全体に $\forall$ をつけて文にしたものを公理とします。

$\mathsf{PA}$ の公理は無限個ありますが、ある文が $\mathsf{PA}$ の公理かどうかは、形を見れば機械的に判定できます。この性質は、不完全性定理の仮定として後で必要になります。

## 証明の例

$\mathsf{PA}$ の中で実際にいくつか証明してみます。形式的な証明をすべて書くと長くなるので、ここでは流れだけを追います。

### 2 + 2 = 4

次の式を示します。

$$
S(S(0)) + S(S(0)) = S(S(S(S(0))))
$$

公理 4 を使うと、足し算の右側の $S$ を外に出すことができます。これを繰り返して、最後に公理 3 を使います。

$$
\begin{aligned}
S(S(0)) + S(S(0)) &= S\bigl(S(S(0)) + S(0)\bigr) && \text{（公理 4）} \\
&= S\bigl(S(S(S(0)) + 0)\bigr) && \text{（公理 4）} \\
&= S(S(S(S(0)))) && \text{（公理 3）}
\end{aligned}
$$

同じやり方で、具体的な自然数どうしの足し算や掛け算の結果は、すべて $\mathsf{PA}$ で証明できます。つまり、$m + n = k$ が成り立つなら

$$
\mathsf{PA} \vdash \overline{m} + \overline{n} = \overline{k}
$$

です。掛け算についても同様です。

### 0 + x = x

公理 3 は $x + 0 = x$ を述べていますが、左右を入れ替えた $0 + x = x$ は公理にはありません。こちらは帰納法を使って証明します。

$\varphi(x)$ を $0 + x = x$ として、公理 7 を使います。

まず $\varphi(0)$、つまり $0 + 0 = 0$ は、公理 3 の $x$ に $0$ を入れたものです。

次に $\varphi(x) \to \varphi(S(x))$ を示します。$0 + x = x$ を仮定すると、

$$
0 + S(x) = S(0 + x) = S(x)
$$

となります。1つ目の等号は公理 4、2つ目の等号は仮定によるものです。

したがって、公理 7 から $\forall x \, (0 + x = x)$ が得られます。

足し算の交換法則や結合法則、掛け算の分配法則なども、同じように帰納法を使って $\mathsf{PA}$ で証明できます。初等的な整数論で出てくる定理のほとんどは、$\mathsf{PA}$ の中で証明できることが知られています。

## 標準モデル

$\mathsf{PA}$ の記号をふつうの意味で解釈したもの、つまり自然数全体の集合に 0、次の数、足し算、掛け算を与えたものを標準モデルと呼び、$\mathbb{N}$ と書きます。文 $\varphi$ が標準モデルで成り立つことを $\mathbb{N} \models \varphi$ と書きます。

$\mathsf{PA}$ の公理はどれも $\mathbb{N}$ で成り立つので、$\mathsf{PA}$ で証明できる文はすべて $\mathbb{N}$ で成り立ちます。

$$
\mathsf{PA} \vdash \varphi \quad \Longrightarrow \quad \mathbb{N} \models \varphi
$$

仮にこの逆も成り立つとすると、どんな文 $\varphi$ についても $\varphi$ か $\lnot\varphi$ のどちらかは $\mathbb{N}$ で成り立つので、$\mathsf{PA}$ は完全だということになります。

第一不完全性定理によれば、逆は成り立ちません。$\mathsf{PA}$ が無矛盾であるかぎり、$\mathsf{PA}$ では証明も反証もできない文が存在します。その文かその否定のどちらかは $\mathbb{N}$ で成り立っているので、$\mathbb{N}$ で成り立つのに $\mathsf{PA}$ では証明できない文が存在することになります。

これは、$\mathsf{PA}$ の公理が足りないということではありません。$\mathsf{PA}$ に新しい公理を付け加えても、公理かどうかを機械的に判定できるかぎり、同じ議論によってまた別の証明できない文が現れます。

## 記号列と自然数

不完全性定理の証明では、論理式や証明といった記号の列そのものを、理論の中で扱う必要があります。

$\mathsf{PA}$ は自然数についての理論ですが、足し算と掛け算が扱えると、有限個の記号の列を自然数として表し、その列に対する操作を自然数の計算として書くことができます。そのため $\mathsf{PA}$ では、自然数についての文を使って、論理式や証明についても述べることができます。

次回は、この対応づけの方法であるゲーデル数を扱います。

## まとめ

- $\mathsf{PA}$ は、$0$、$S$、$+$、$\times$ を使って自然数を扱う一階の理論
- 公理は、後者関数についての2つ、足し算と掛け算の定義の4つ、そして数学的帰納法の公理図式
- 具体的な数の計算や、初等的な整数論の定理の多くは $\mathsf{PA}$ で証明できる
- 標準モデルで成り立つ文がすべて $\mathsf{PA}$ で証明できるわけではない
